# Technology Product Website

## Project
A simple product webpage for fictional TechNova wireless headphones, made with HTML and CSS.

## Features
- Product introduction
- Three product features
- Product image and sample price
- Contact information

## Files
- `index.html` - webpage structure
- `style.css` - webpage design

## How to Run
1. Open this folder.
2. Double-click `index.html`.
3. The webpage opens in your browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `style.css` to the repository.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.

Note: TechNova and the product details are fictional sample content.
